# Menambah Write-up

1. Buat folder dengan nama huruf kecil dan tanda hubung di bawah platform yang sesuai, misalnya `hackthebox/nama-mesin/` atau `tryhackme/nama-room/`.
2. Salin [template](templates/WRITEUP.md) menjadi `README.md` di folder tersebut.
3. Simpan gambar di folder di sebelah `README.md` dan gunakan tautan relatif, misalnya `![Hasil enumerasi](images/01-enumeration.png)`.
4. Tambahkan tautan write-up ke `README.md` utama dan indeks platform.
5. Periksa bahwa semua tautan berkas dan gambar dapat dibuka sebelum mengirim perubahan.
