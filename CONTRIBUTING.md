# Adding a Write-up

1. Create a folder with a lowercase, hyphenated name under the appropriate platform, such as `hackthebox/machine-name/` or `tryhackme/room-name/`.
2. Copy the [template](templates/WRITEUP.md) into that folder as `README.md`.
3. Store images in a folder alongside `README.md` and use relative links, such as `![Enumeration results](images/01-enumeration.png)`.
4. Add a link to the write-up in the main `README.md` and the platform index.
5. Check that all file and image links work before submitting changes.
