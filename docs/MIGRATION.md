## History and Evidence

- The complete commit history of each source repository's `main` branch was preserved by merging the original history. Each source had one `main` branch and no tags when imported.
- The `imports/<source-repository-name>` tags point to the source commits before consolidation. Use these tags to view the original filenames and locations.
- The `pre-consolidation-2026-10-10` tag points to the main repository before consolidation.
- Images and evidence checksums were preserved without changes.
- Nested report folders were flattened, with the complete illustrated report becoming each machine's `README.md`. Duplicate reports that were identical, contained only a title, or were fully covered by the complete report were consolidated. The original versions remain available in the commit history.
- TryHackMe files were moved without content changes during consolidation.
- Ten image links in the Reactor report referenced files absent from the source repository snapshot. These links were replaced with missing-image notices that retain the original descriptions and filenames.
- The directory listing in the Blue report was updated to reflect its new location.

## Scope

Bug bounty reports, CVE advisories, coursework, web projects, and `Cybersecurity-Lab` were outside the scope of CTF consolidation. The `overthewire_bandit_1-10` repository was an empty duplicate that had already been archived before migration and contained nothing to import.

## Archived Repositories

All 18 source repositories were archived after the consolidated commit was verified on GitHub. Each original README links to the new write-up location, and the repository homepage and description point to the main repository. The original repositories remain available to preserve their URLs and history.
